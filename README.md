# Analog Click — Settings Files and Press Kit

Sample settings files and press materials for **[Analog Click: Haptic Switches](https://apps.apple.com/app/id6829236610)**, an iPhone app of metal switches, rollers, reels, and dials you can feel.

[日本語は下にあります](#日本語)

## Settings files

A settings file is a JSON file that holds a screen layout and the actions linked to moves. Importing one requires the Full Version.

| File | What it does |
| --- | --- |
| [analog-click-boombox.json](settings/analog-click-boombox.json) | Keys play, pause, and skip. The reel chooses songs, and the roller sets the volume. |
| [analog-click-focus.json](settings/analog-click-focus.json) | Slide and spin the reel to start a 25-minute or 5-minute timer. |
| [analog-click-flashlight.json](settings/analog-click-flashlight.json) | Button: flashlight. Lever: blink. Switch: SOS. Bolt: white screen. Roller: brightness. |

**How to use**

1. Open a file above, then tap the download button (Download raw file) and save it to the Files app.
2. In Analog Click, open Settings (the gear icon) and tap **Import Settings File**.
3. Choose the file. The layout is replaced, and the actions are added to My Set.

You can also export your own layout from Settings and share it.

## 日本語

[Analog Click](https://apps.apple.com/app/id6829236610)（金属のスイッチやダイヤルを指で動かす感触を楽しむiPhoneアプリ）の、設定ファイルのサンプルと紹介用の素材です。

### 設定ファイル

画面の配置と、動作の組み合わせをまとめたJSONファイルです。読み込むにはフル版が必要です。

| ファイル | 内容 |
| --- | --- |
| [analog-click-boombox.json](settings/analog-click-boombox.json) | ラジカセ。矢印ボタンで再生と曲送り、リールで曲選び、ローラーで音量 |
| [analog-click-focus.json](settings/analog-click-focus.json) | 集中タイマー。スライダーとリールで25分か5分のタイマー |
| [analog-click-flashlight.json](settings/analog-click-flashlight.json) | ライト。ボタンでライト、レバーで点滅、スイッチでSOS、ボルトで白い画面、ローラーで明るさ |

**使い方**

1. 上のファイルを開き、ダウンロードボタン（Download raw file）を押して、「ファイル」アプリに保存します。
2. Analog Clickの設定（歯車のアイコン）で「設定ファイルを読み込む」を押します。
3. 保存したファイルを選びます。配置は置き換わり、動作はマイセットに追加されます。
